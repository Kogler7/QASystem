## 采购管理域
// 术语名称: 采购管理域
// 术语定义（术语标准定义）: 围绕采购业务活动及其相关对象、流程、金额、数量、风险、协同情况等进行管理、统计、分析与决策的业务领域。
// 同义词: 采购业务域

## 电子采购
// 术语名称: 电子采购
// 术语定义（术语标准定义）: 依托电子化平台开展的采购活动，包括采购申请、招标、开标、评标、中标等采购过程的线上化处理。
// 同义词: 线上采购、电子化采购

## 公开采购
// 术语名称: 公开采购
// 术语定义（术语标准定义）: 按照公开规则面向社会或合格供应商公开发布采购信息并组织实施的采购方式。
// 同义词: 公开招采、公开招标采购

## 非公开采购
// 术语名称: 非公开采购
// 术语定义（术语标准定义）: 未采用公开方式开展的采购活动，通常包括邀请采购、定向采购或其他非公开组织方式。
// 同义词: 非公开招采

## 标段
// 术语名称: 标段
// 术语定义（术语标准定义）: 在采购项目中按内容、范围、专业或实施边界划分形成的独立采购单元。
// 同义词: 包段、采购标段

## 中标金额
// 术语名称: 中标金额
// 术语定义（术语标准定义）: 在采购活动中最终确定由中标方承接的合同或成交金额。
// 同义词: 成交金额、中选金额

## 采购品类
// 术语名称: 采购品类
// 术语定义（术语标准定义）: 按物资、服务或工程属性对采购对象进行划分形成的类别。
// 同义词: 采购类别、物资品类

## 采购申请
// 术语名称: 采购申请
// 术语定义（术语标准定义）: 业务部门基于业务需求提出的采购需求申请行为或申请记录。
// 同义词: 请购申请、请购单

## 异常标段
// 术语名称: 异常标段
// 术语定义（术语标准定义）: 在采购执行过程中出现异常情形、需触发风险识别或预警的标段。
// 同义词: 风险标段、异常采购标段

## 异常率
// 术语名称: 异常率
// 术语定义（术语标准定义）: 异常对象数量占全部对象数量的比例，用于衡量异常发生程度。
// 同义词: 风险率、异常占比

## 代理商采购
// 术语名称: 代理商采购
// 术语定义（术语标准定义）: 通过代理商渠道完成的采购活动。
// 同义词: 代理采购

## 采购合同金额
// 术语名称: 采购合同金额
// 术语定义（术语标准定义）: 在采购合同中约定的合同金额汇总值。
// 同义词: 合同采购金额、采购合同额

## 区域采购
// 术语名称: 区域采购
// 术语定义（术语标准定义）: 按行政区划、经营区域或地理区域划分统计的采购活动。
// 同义词: 分区域采购

## 区域
// 术语名称: 区域
// 术语定义（术语标准定义）: 用于统计采购业务的地理空间维度，如省份、片区或大区。
// 同义词: 地区、省域

## 供应商
// 术语名称: 供应商
// 术语定义（术语标准定义）: 向采购主体提供物资、工程或服务的法人或其他组织。
// 同义词: 供方、供货商

## 供应商采购金额排名
// 术语名称: 供应商采购金额排名
// 术语定义（术语标准定义）: 按供应商对应采购金额从高到低形成的排序结果。
// 同义词: 供应商金额排名、供应商采购额排名

## 独家采购
// 术语名称: 独家采购
// 术语定义（术语标准定义）: 因供应来源唯一、技术专属或其他限制条件，仅能向单一对象实施的采购活动。
// 同义词: 单一来源采购（常见近义用法）

## 独家采购占比
// 术语名称: 独家采购占比
// 术语定义（术语标准定义）: 独家采购金额占采购总金额的比例，用于衡量采购集中性和潜在风险。
// 同义词: 独家采购比例、单一来源采购占比

## 订单协同
// 术语名称: 订单协同
// 术语定义（术语标准定义）: 围绕采购订单在上下游、部门间或系统间进行的信息协同、流转与协作处理过程。
// 同义词: 订单协作、订单协同处理

## 运行指标
// 术语名称: 运行指标
// 术语定义（术语标准定义）: 用于反映采购业务运行规模、进度、数量、金额等客观状态的指标。
// 同义词: 业务运行指标

## 管理指标
// 术语名称: 管理指标
// 术语定义（术语标准定义）: 用于支撑采购管理评价、目标考核和经营管控的指标。
// 同义词: 管控指标

## 风险提示指标
// 术语名称: 风险提示指标
// 术语定义（术语标准定义）: 用于识别、度量和提示采购风险水平或异常情况的指标。
// 同义词: 风险指标、预警指标

## 一级指标
// 术语名称: 一级指标
// 术语定义（术语标准定义）: 在指标体系中处于较高层级、反映某一类核心业务状态的指标。
// 同义词: 核心指标

## 二级指标
// 术语名称: 二级指标
// 术语定义（术语标准定义）: 对一级指标进行细化分解、用于补充说明或支撑分析的指标。
// 同义词: 明细指标、细分指标
