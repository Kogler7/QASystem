# 知识图谱问答模块 (QA) - 接口文档

## 1. 模块概述

知识图谱问答模块（QA）是一个基于 Neo4j 知识图谱的智能问答系统，采用模块化设计，包含两个核心组件：问题定义和答案生成。该模块支持自然语言问题理解、实体链接、知识图谱检索和答案生成。

### 核心特性

- **模块化设计**：两个独立组件（问题定义、答案生成）可单独调用或组合使用
- **多跳推理**：支持基于知识图谱的深度推理，自动探索实体间的关系路径
- **实体链接**：自动识别问题中的实体并链接到知识图谱
- **大模型驱动**：利用 LLM 进行关系选择、实体评分和答案生成
- **数据来源追踪**：自动提取并返回答案的数据来源信息
- **推理日志**：记录完整的推理过程，支持可追溯性分析
- **单步问答**：整合后的 AnswerGenerationTool 支持一步完成图谱检索和答案生成
- **结构化答案**：生成包含业务活动、指标匹配、推导过程和最终答案的结构化输出

## 2. 核心组件

### 2.1 组件架构

```
用户问题
    ↓
┌─────────────────────────────────────┐
│  Neo4jQAService (answer_solve.py)   │
│  - 协调整个问答流程                  │
│  - 提供统一的服务接口                │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│  组件1: ProblemDefinitionTool       │
│  - 问题定义与结构化                 │
│  - 实体识别与链接                   │
│  - 问题模型生成                     │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│  组件2: AnswerGenerationTool        │
│  - 方案规划与知识图谱检索（ToG搜索）│
│  - 推理路径生成                     │
│  - 答案生成与优化                   │
│  - 数据来源提取                     │
│  - 结构化答案输出                   │
└─────────────────────────────────────┘
    ↓
最终答案（结构化格式）
```

### 2.2 组件说明

| 组件名称 | 文件位置 | 功能描述 |
|---------|---------|---------|
| **ProblemDefinitionTool** | `tools/problem_definition.py` | 问题定义工具，将自然语言问题转化为结构化的问题模型 |
| **AnswerGenerationTool** | `tools/answer_generation.py` | 答案生成工具，整合方案规划和答案生成功能，一步完成问答流程 |
| **Neo4jQAService** | `answer_solve.py` | 问答服务封装类，协调组件完成完整问答流程 |

## 3. Python 接口

### 3.1 Neo4jQAService 类

**位置**：`algorithm/ans/QA/answer_solve.py`

#### 初始化

```python
from algorithm.ans.QA.answer_solve import Neo4jQAService

# 初始化服务（使用默认配置）
service = Neo4jQAService()

# 关闭连接
service.close()
```

#### 方法说明

##### answer_question

基础问答接口，直接返回答案字符串。

```python
answer = service.answer_question("公开采购与非公开采购金额构成如何？")
```

**参数**：
- `question` (str): 用户输入的自然语言问题

**返回值**：
- `str`: 最终答案字符串（结构化格式）

**示例**：
```python
service = Neo4jQAService()
answer = service.answer_question("公开采购与非公开采购金额构成如何？")
print(answer)
# 输出:
# o根据业务模型识别到该问题对应的业务活动是：公开采购与非公开采购金额对比分析
# o根据指标模型匹配：CG_003 公开采购中标金额
# o推导：公开采购金额可通过指标CG_003计算得出（SQL: SELECT SUM(gkcaigouamount) AS value FROM ads_dzcg_bidsum WHERE year = #{year}），非公开采购金额需补充相关指标数据
# o因此，业务被转化为用指标描述的业务，最终答案：公开采购金额通过CG_003指标计算，非公开采购金额需补充对应指标数据才能完成构成分析
service.close()
```

##### answer_question_with_details

带详细信息的问答接口，返回完整的推理过程。

```python
result = service.answer_question_with_details("公开采购与非公开采购金额构成如何？")
```

**参数**：
- `question` (str): 用户输入的自然语言问题

**返回值**：
- `Dict`: 包含答案和详细推理过程的字典

**返回结构**：
```python
{
    "success": True,
    "answer": "结构化答案字符串",
    "raw_details": {
        "推理日志": [...]
    }
}
```

#### AnswerGenerationTool

**位置**：`algorithm/ans/QA/tools/answer_generation.py`

AnswerGenerationTool 已整合方案规划功能，支持单步完成问答流程。

```python
from algorithm.ans.QA.tools.answer_generation import AnswerGenerationTool
from algorithm.ans.QA.neo4j_client import MultiServerWikidataQueryClient
from algorithm.ans.QA.config import config

# 初始化
client = MultiServerWikidataQueryClient(
    neo4j_uri=config.NEO4J_URI,
    username=config.NEO4J_USER,
    password=config.NEO4J_PASSWORD
)
tool = AnswerGenerationTool(client, config)

# 主要调用方式 - 传入意图识别的结构化输出
intent_output = {
    "Domain": "采购管理域",
    "Scenario": "采购结构分析",
    "Object": "采购金额结构",
    "Goal": "公开采购与非公开采购金额构成如何？",
    "IntentType": "看构成"
}
result = tool.generate_answer(intent_output)

# 简化调用方式 - 直接传入问题字符串
question = "公开采购与非公开采购金额构成如何？"
result = tool.generate_answer(question)
```

**返回结构**：
```python

    "success": True,
    "answer": """

    """.strip()

```

**结构化答案格式说明**：

### 5.1 问题模型 (ProblemModel)

```json
{
  "问题ID": "PROB-20260409183049",
  "问题描述": "公开采购与非公开采购金额构成如何？",
  "问题类型": "描述型问题",

}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| 问题ID | string | 问题唯一标识符，格式为 PROB-YYYYMMDDHHMMSS |
| 问题描述 | string | 问题的完整描述 |

| 干系人 | array | 相关干系人列表 |
| 目标 | array | 问题的目标列表 |
| 当前状态 | string | 问题的当前状态 |
| 相关实体 | array | 问题中识别出的相关实体列表 |
| 创建时间 | string | 问题模型的创建时间（ISO格式） |

## 6. 使用示例

### 6.1 Python 完整流程示例

```python
from algorithm.ans.QA.answer_solve import Neo4jQAService

# 初始化服务
service = Neo4jQAService()

# 测试问题

    "公开采购与非公开采购金额构成如何？",
    "公开采购比例有什么属性",
    "电子采购异常标段数是多少",
    "采购标段数的信息有哪些",
    "列车A发生故障的原因是什么",
    "采购申请数量是多少"
]

for question in questions:
    print(f"\n{'=' * 80}")
    print(f"问题: {question}")
    print("=" * 80)
    
    # 基础问答
    answer = service.answer_question(question)
    print(f"\n答案:\n{answer}")
    
    # 带详细信息的问答
    result = service.answer_question_with_details(question)
    if result.get("success"):
        print(f"\n推理日志数量: {len(result.get('raw_details', {}).get('推理日志', []))}")

# 关闭连接
service.close()
```
