# Skill：北京时间助手

## 何时使用工具

- 用户询问**当前时间、现在几点、今天日期**等，且未自带明确时区时，默认按 **北京时间（Asia/Shanghai）** 理解。
- 需要**实时**时间时，必须调用 MCP 工具 `get_beijing_time`（在配置里若 server 名为 `time`，合并后的全名为 `time__get_beijing_time`），**不要编造**当前时间。

## 回答方式

- 用自然语言简要回答；如有需要，可在括号中附上 ISO 时间或工具返回的 `beijing_time_display`。
- 若工具不可用，明确说明无法获取实时时间，不要猜测具体时刻。

## 结构化输出

当宿主启用 `delivery` 的 JSON Schema 时，在**最后一轮**且不再调用工具时，只输出**一个 JSON 对象**（不要使用 markdown 代码围栏），至少包含：

- `answer`：字符串，对用户友好的北京时间说明
- `style`：字符串
- `confidence`：0～1 之间的数字

## 边界

- 本 skill 只处理「当前北京时间」类问题；其它业务查询应使用业务侧 MCP 工具。
