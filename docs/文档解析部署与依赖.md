# 文档解析部署与依赖

本文记录文档解析组件的格式转换、镜像依赖、模型挂载、GPU 配置和运行检查。解析参数与引擎选择行为见[文档解析行为规范](文档解析行为规范.md)。

## 1. 格式转换

| 输入与引擎 | 前置处理 |
|---|---|
| DOCX/DOC/PPTX/PPT 使用 `vlm` 或 `mineru` | LibreOffice 转 PDF，再进入解析流程 |
| PNG/JPG/JPEG 使用 `vlm` 或 `mineru` | Pillow 封装为单页 PDF，再进入解析流程 |
| PPT 使用 `docling` | LibreOffice 转 PPTX，再由 Docling 解析 |
| PPTX、图片使用 `docling` | Docling 原生解析 |
| Markdown、TXT | 按 UTF-8 BOM/UTF-8 或 GB18030 直接解码 |

## 2. 镜像依赖

| 依赖 | 安装来源 | 用途 |
|---|---|---|
| LibreOffice Core | Dockerfile 系统包 | Office 格式转换基础能力 |
| LibreOffice Writer | Dockerfile 系统包 | DOC/DOCX 转换 |
| LibreOffice Impress | Dockerfile 系统包 | PPT/PPTX 转换 |
| Noto CJK | Dockerfile 系统包 | 中文字体渲染 |
| Pillow | `backend/requirements.txt` | 图片转 PDF |
| Docling | `backend/requirements.txt` | `docling` 引擎 |
| MinerU | `backend/requirements.txt` | `vlm` 和 `mineru` 引擎 |

镜像构建会检查 LibreOffice 组件、中文字体、Python 模块以及 Docling 的 PPTX/IMAGE 输入能力。任一检查失败时镜像构建终止。

容器内 LibreOffice 路径：

```text
/usr/bin/soffice
```

## 3. 模型挂载

模型目录通过 Compose 挂载到容器 `/models`：

```env
HOST_MODELS_DIR=./deploy/models
MINERU_MODEL_PIPELINE_PATH=/models/hub/models/OpenDataLab/PDF-Extract-Kit-1___0
MINERU_MODEL_VLM_PATH=/models/hub/models/OpenDataLab/MinerU2___5-2509-1___2B
```

`mineru` 只检查 Pipeline 模型目录，`vlm` 只检查 VLM 模型目录。

## 4. GPU 部署

默认 Compose 为后端申请全部 NVIDIA GPU：

```yaml
services:
  backend:
    gpus: all
```

部署机需要安装 NVIDIA 驱动、NVIDIA Container Toolkit，并使用支持 `gpus` 字段的 Docker Compose。CPU-only 部署需要从 Compose 中移除 `gpus: all`。

容器内检查：

```bash
docker compose exec backend python -c "import torch; print(torch.cuda.is_available(), torch.cuda.device_count())"
docker compose exec backend nvidia-smi
```

## 5. 构建与验证

```bash
docker build -t qasystem-backend:latest .
docker run --rm qasystem-backend:latest libreoffice --headless --version
docker run --rm qasystem-backend:latest python -c "import docling, mineru, PIL"
```

Compose 使用本地镜像并配置 `pull_policy: never`。Dockerfile 或依赖变更后需要重新构建镜像。

## 6. 运行错误

依赖或转换能力不可用时，解析错误会返回具体原因，包括：

- 未找到 LibreOffice/soffice
- LibreOffice Writer 或 Impress 转换失败及命令输出
- LibreOffice 转换超时
- 缺少 Pillow
- 图片损坏或格式不正确
- 缺少 Docling、MinerU 等 Python 模块
- MinerU 所选路线的模型目录缺失
