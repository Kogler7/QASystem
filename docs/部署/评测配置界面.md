# 本轮评测配置界面

```bash
python3 eval/configure.py
```

SSH 请使用交互终端，例如 `ssh -t 88zjwei`。Windows 使用 `.venv/Scripts/python.exe eval/configure.py`。

界面每次启动一份空白覆盖计划，不读取或保存 profile、不读取任何评测 YAML。所有值最终转换为 `eval/run.py` 的命令行参数。CLI 默认值和说明直接读取当前代码参数定义，没有另外一套默认配置文件。

| 按键 | 操作 |
| --- | --- |
| ↑↓ / PgUp / PgDn | 移动和翻页 |
| ←→ / Tab | 切换分类 |
| Enter | 输入本轮参数 |
| Space | 切换布尔开关 |
| d / 编辑时留空 | 删除本轮覆盖，采用 CLI 默认或应用默认 |
| p | 预览最终命令，不执行 |
| v | 明确执行 `--dry-run`，只扫描数据集 |
| r | 预览命令，再输入 `run` 才真正评测 |
| q | 退出，丢弃本轮计划 |

键靠左、值靠右；`[覆写]` 表示当前会话的显式参数，`[继承]` 表示未覆盖。未指定抽取算法或模型时，实际值由 Backend 决定；裁判可沿用应用裁判设置，显式 CLI 优先。打开界面不会部署模型、修改应用配置或重启服务。

## 命令行例子

```bash
# 完整后台沉淀链路，明确本轮算法、模型与裁判
python3 eval/run.py --groups official --backend-url http://127.0.0.1:8006 --extract-version v3.1 --extract-provider siliconflow --extract-model deepseek-ai/DeepSeek-V4-Flash --judge-model deepseek-flash --judge-adapter chat --judge-base-url https://api.deepseek.com/v1 --judge-key-env DEEPSEEK_API_KEY --judge-max-concurrency 4

# 固定切片，只换抽取模型；本轮使用小模型裁判
python3 eval/run.py --groups official --mode extract --from-run tmp/eval/runs/冻结批次 --extract-model Qwen/Qwen3.5-4B --judge-model Qwen/Qwen3.5-4B --judge-adapter chat --judge-base-url http://127.0.0.1:9998/v1 --judge-batch-size 4 --judge-golden-batch-size 8 --judge-max-tokens 4096

# mini 范围与抽样也临时指定
python3 eval/mini_eval.py --mini-cases-per-type 1 --mini-per-type official=2 --mini-selection first --mini-seed 42 --dry-run
```

`--params`、`eval/params.yaml` 和 `eval/quick_params.yaml` 已删除；工作区配置和 `eval/.env` 不会抢占本轮参数。旧实验需要将 YAML 字段改成对应 CLI。Backend/MCP 地址、轮询、judge 超时/token/窗口/并发/响应格式、切片策略/大小/overlap/自适应开关、存储和质量门禁均提供 CLI，可查 `python3 eval/run.py --help`。

模型权重、供应商端点和凭据仍由应用部署管理。密钥只从已命名环境变量取得，CLI/TUI 不接受原始密钥。根 `.env` 保留现有应用凭据兼容；评测 Backend 地址使用本轮 CLI，不被旧 QASYSTEM_BACKEND_URL 自动替换。实际执行使用参数列表，不经过 shell。

运行输出仍写 `tmp/eval/runs/`。`params.resolved.json` 记录本轮实际解析参数供审计，不是下一轮的输入配置。界面不提供自动持久化、配置加载或配置导出；可复制 `p` 显示的命令自行保存。只有显式 `--from-run` 等参数才复用指定运行产物。
