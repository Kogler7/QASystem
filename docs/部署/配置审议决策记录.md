# 配置审议决策记录

记录用户对最终配置清单的逐组决定。先审新版需要保留的配置，再对照 88；不把旧部署实际值当作新设计依据。用户决定、实现完成和部署生效是三种不同状态。

## 2026-10-14 · 第一组：环境与基础路径

用户决定：“环境镜像配置可以保留，其余按你说的做。”

| 配置项 | 决定 | 理由 | 状态 |
| --- | --- | --- | --- |
| QASYSTEM_ENV_IMAGE | 保留用户配置 | 可选择统一环境镜像的标签；镜像基名仍遵守 qasystem-env-v1 约定 | 已决定 |
| QASYSTEM_SOURCE_DIR | 保留用户配置 | 宿主源码部署位置可能不同 | 已决定 |
| HOST_MODELS_DIR | 保留用户配置 | 宿主权重所在磁盘可能不同 | 已决定 |
| QASYSTEM_LOAD_DOTENV | 移除开关，统一启动时自动判断 | 容器/已注入环境不重复加载 dotenv；本地未托管启动按约定加载 | 实现中 |
| QASYSTEM_RUNTIME_CONFIG_DIR | 移除独立配置，从部署根目录推导 runtime-config/ | 统一配置、历史和挂载位置；旧目录内容需要可审核迁移 | 实现中 |
| PYTHONPATH | 固定为内部启动约定 | 用户不需要维护容器内部导入路径 | 实现中 |
| PYTHONUNBUFFERED | 固定开启 | 日志及时输出作为服务启动约定 | 实现中 |

实现委派给 config_foundation_cleanup subagent，负责代码、迁移、声明版本、测试、文档和提交。任何服务器实际配置变化仍必须经用户在 CLI UI 审核，不由本记录自动批准。

## 待审 · 第二组：Backend / Agent 对外入口

以下仅为建议，尚未成为用户决定。

| 配置项 | 当前默认 | 建议 | 作用 |
| --- | --- | --- | --- |
| BACKEND_HOST_PORT | 8006 | 保留 | Backend 暴露到宿主机的端口；容器内部 8000 固定 |
| AGENT_HOST_PORT | 9180 | 保留 | Agent 暴露到宿主机的端口；容器内部 9180 固定 |
| BACKEND_BIND | 0.0.0.0 | 保留 | Backend 的宿主监听地址，可限制仅本机访问 |
| AGENT_BIND | 0.0.0.0 | 保留 | Agent 的宿主监听地址，可以与 Backend 有不同暴露范围 |

两服务当前默认地址相同，但作用对象不同；合并为一个开关会失去独立控制。决策模型内部监听与内部服务端口另组审议，不与宿主对外端口混在一起。
