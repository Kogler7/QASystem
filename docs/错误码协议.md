# 错误码协议

本文定义算法 HTTP 接口统一错误结构、错误码分段、HTTP 状态和重试语义。

## 统一结构

```json
{
  "code": 4002,
  "info": "LLM 请求超时",
  "data": null,
  "error": {
    "type": "LLM_TIMEOUT",
    "stage": "graph_extraction",
    "retryable": true,
    "details": {"failed_count": 1}
  }
}
```

| 字段 | 说明 |
| --- | --- |
| `code` | 稳定数值错误码，用于程序分支 |
| `info` | 面向人阅读的错误说明，不作为程序判断依据 |
| `data` | 通常为 `null`；聚合流水线失败时可能包含已生成的部分产物 |
| `error.type` | 稳定字符串标识，便于日志、监控和跨语言使用 |
| `error.stage` | 失败的处理阶段 |
| `error.retryable` | 是否可以在不修改请求的情况下重试 |
| `error.details` | 诊断信息，不保证跨版本字段完全稳定 |

调用方不得解析 `info` 或 `details` 中的自然语言判断错误类型，应使用 `code` 或 `error.type`。

## 请求与资源（1000–1999）

| code | type | HTTP | 可重试 | 含义 |
| ---: | --- | ---: | :---: | --- |
| `1000` | `INVALID_REQUEST` | 400/422 | 否 | 请求字段或业务前置条件无效 |
| `1001` | `UNSUPPORTED_FILE_TYPE` | 415 | 否 | 文件类型不支持 |
| `1002` | `PAYLOAD_TOO_LARGE` | 413 | 否 | 请求体或文件超过限制 |
| `1003` | `RESOURCE_NOT_FOUND` | 404 | 否 | 通用资源不存在 |

## 文档解析（2000–2999）

| code | type | HTTP | 可重试 | 含义 |
| ---: | --- | ---: | :---: | --- |
| `2000` | `DOCUMENT_PARSE_FAILED` | 422 | 否 | 未分类解析失败 |
| `2001` | `DOCUMENT_CONTENT_EMPTY` | 422 | 否 | 解析结果为空 |
| `2002` | `PARSER_UNAVAILABLE` | 503 | 是 | 解析模型、程序或依赖不可用 |
| `2003` | `DOCUMENT_CONVERT_FAILED` | 422 | 否 | 文档格式转换失败 |

## 文本切片（3000–3999）

| code | type | HTTP | 可重试 | 含义 |
| ---: | --- | ---: | :---: | --- |
| `3000` | `CHUNK_FAILED` | 422 | 否 | 未分类切片失败 |
| `3001` | `INVALID_CHUNK_CONFIG` | 422 | 否 | 切片配置无效 |
| `3002` | `CHUNK_RESULT_EMPTY` | 422 | 否 | 没有产生切片 |
| `3003` | `CHUNK_OFFSET_FAILED` | 500 | 否 | 无法建立原文字符偏移 |

## LLM 与图谱抽取（4000–4999）

| code | type | HTTP | 可重试 | 含义 |
| ---: | --- | ---: | :---: | --- |
| `4000` | `GRAPH_EXTRACTION_FAILED` | 502 | 是 | 未分类图谱抽取失败 |
| `4001` | `LLM_REQUEST_FAILED` | 502 | 是 | LLM 请求失败 |
| `4002` | `LLM_TIMEOUT` | 504 | 是 | LLM 请求超时 |
| `4003` | `LLM_RATE_LIMITED` | 429 | 是 | LLM 限流或配额不足 |
| `4004` | `LLM_RESPONSE_INVALID` | 502 | 是 | LLM 响应无法解析 |
| `4005` | `PARTIAL_EXTRACTION_FAILED` | 502 | 是 | 部分切片抽取失败 |
| `4006` | `ONTOLOGY_INVALID` | 422 | 否 | 本体为空或无效 |

## 向量、图谱与存储（5000–7999）

| code | type | HTTP | 可重试 | 含义 |
| ---: | --- | ---: | :---: | --- |
| `5000` | `EMBEDDING_FAILED` | 500 | 是 | 未分类向量化失败 |
| `5001` | `EMBEDDING_MODEL_UNAVAILABLE` | 503 | 是 | 向量模型不可用 |
| `5002` | `VECTOR_COUNT_MISMATCH` | 500 | 否 | 输入数量与向量数量不一致 |
| `6000` | `CONFIDENCE_FAILED` | 500 | 是 | 置信度计算失败 |
| `6001` | `GRAPH_INVALID` | 422 | 否 | Graph 结构无效 |
| `6002` | `GRAPH_STORAGE_FAILED` | 502 | 是 | Neo4j 写入失败 |
| `7000` | `FILE_SERVICE_FAILED` | 502 | 是 | 外部文件服务上传失败 |
| `7001` | `VECTOR_STORE_FAILED` | 502 | 是 | 外部向量存储接口失败 |
| `7002` | `VECTOR_ID_COUNT_MISMATCH` | 502 | 否 | 向量存储返回的 ID 数量与输入不一致 |

## 外部依赖与内部错误（8000–9999）

| code | type | HTTP | 可重试 | 含义 |
| ---: | --- | ---: | :---: | --- |
| `8000` | `DEPENDENCY_UNAVAILABLE` | 503 | 是 | 外部依赖不可用 |
| `8001` | `DEPENDENCY_TIMEOUT` | 504 | 是 | 外部依赖超时 |
| `9000` | `INTERNAL_ERROR` | 500 | 否 | 未分类内部错误 |
| `9001` | `CONFIGURATION_ERROR` | 500 | 否 | 服务配置错误 |

## HTTP 状态约定

业务错误码不会替代 HTTP 状态：

| HTTP | 使用场景 |
| ---: | --- |
| `400` | 请求格式或配置无效 |
| `404` | 资源不存在 |
| `413` | 请求体或文件过大 |
| `415` | 文件类型不支持 |
| `422` | 请求语法正确但业务语义无效 |
| `429` | 限流或配额不足 |
| `500` | 服务内部计算错误 |
| `502` | LLM、文件服务或数据库等下游调用失败 |
| `503` | 模型、程序或外部依赖暂不可用 |
| `504` | 下游依赖超时 |

## 重试建议

- `retryable=false`：调用方应修改请求、配置或资源后再调用。
- `retryable=true`：调用方可以指数退避重试，并设置最大次数。
- HTTP `429` 应优先遵循服务端未来可能返回的 `Retry-After`。
- 聚合流水线返回部分产物时，仍应把整个请求视为失败；部分产物仅用于排障或人工恢复。
