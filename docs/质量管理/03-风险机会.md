# 风险和机会计划与跟踪表（交大算法团队）

> 版本：V0.1（内容基线）｜项目已开展约 8 个月，日期和责任人以甲方模板回填时确认。未在仓库证实的事项标记为“待确认”。

## 1. 管理计划

- 风险编号：`RISK-XX`；机会编号：`OPP-XX`。
- 评估维度：发生概率 P（1–5）、影响 I（1–5），风险值 `P×I`；1–5 低、6–12 中、13–25 高。
- 高风险每周跟踪，中风险每两周跟踪，低风险在里程碑复核。
- 责任边界：交大负责知识沉淀算法、Agent loop 问题求解算法、模型/图谱质量与算法接口；雪浪负责系统集成、部署和主测试；信息公司/甲方负责业务口径和外部接口开通。
- 阈值触发后须建立行动项、截止日期、验证证据和关闭结论。
