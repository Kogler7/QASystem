# 公文结构单元与抽取字段规则

适用版本：`v3` 与 `latest`。公文提示词审计版本为 `v11`；两者维护独立实体代码目录。规则按正文和编译后的本体执行，不在运行时读取评测 golden。

## 结构识别与命名

解析后的 Markdown 标题前缀先移除。有编号且有题名的条目用原文题名；单独的章标题使用章题名；章下未命名条目使用“章题名第N条”；自然段使用“第N段”；附件段使用“附件说明”。条目编号 1–99 使用汉字，超过该范围保留数字，不能使整份文档解析失败。

正文在明确的收文处理单、领导批示等表单标题或字段标签处结束。正文句子中提及这些词不会结束正文；Markdown 表格中的字段标签可识别。页码、联系人、抄送及印发信息不作为正文结构单元。

## 字段约束

结构单元的“单元标识”和活动“优先级”属于系统赋值字段，不由抽取生成。附件信息对象名称使用原文对象名，不添加附件序号前缀。活动类型、主体类型、组织层级、约束类型和强制程度按本体规则表达；主体类型与组织层级不得互相填充。

## 验证范围

单测覆盖章与条、自然段、附件、Markdown 标题、版头版记、表单边界、正文提及表单词、大编号及提示词版本。命名和字段输出会发生变化；单测通过不代表模型抽取质量已提升，实际收益需要服务链路评测与基线对比。此变更未修改部署环境变量，也未执行服务器部署。
