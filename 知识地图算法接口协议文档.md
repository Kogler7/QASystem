# 知识地图算法接口协议文档 V2

本文档面向调用方。所有接口统一由算法服务提供，默认服务地址如下：

```text
Base URL: http://127.0.0.1:8080
```

## 通用约定

| 项目         | 说明                                                                                  |
| ------------ | ------------------------------------------------------------------------------------- |
| 认证方式     | 无                                                                                    |
| 字符编码     | UTF-8                                                                                 |
| 成功标识     | 响应 JSON 中`code=0` 表示业务成功                                                   |
| 服务健康检查 | `GET /api/knowledge/health`                                                         |
| 文件解析支持 | `.pdf`、`.docx`、`.doc`、`.xlsx`、`.xls`、`.csv`、`.html`、`.htm`     |
| 运行依赖     | 算法服务 8080、Neo4j、Elasticsearch、Milvus；知识抽取需要可用的 OpenAI-compatible LLM |

## 1. 知识沉淀接口

统一的知识沉淀入口。接收原始文件，自动完成文档解析、知识抽取、文本切片和向量化，并返回沉淀结果。

| 项目         | 说明                                                       |
| ------------ | ---------------------------------------------------------- |
| URL          | `POST /api/knowledge/precipitation`                      |
| 完整地址     | `POST http://127.0.0.1:8080/api/knowledge/precipitation` |
| Content-Type | `multipart/form-data`                                    |
| 认证方式     | 无                                                         |

### 请求参数

| 字段                   | 类型   | 必填 | 说明                                                                  |
| ---------------------- | ------ | ---- | --------------------------------------------------------------------- |
| `file`               | file   | 是   | 待解析的原始文档文件                                                  |
| `ontology`           | string | 是   | PlantUML 本体定义                                                     |
| `lang`               | string | 否   | 文档语言，默认`ch`，可选 `en`                                     |
| `parser_engine`      | string | 否   | 解析引擎；不传则按文件类型使用默认解析器                              |
| `chunk_type`         | int    | 否   | 切片类型：`0` 语义/递归默认、`1` 符号、`2` 递归、`3` Markdown |
| `chunk_size`         | int    | 否   | 切片大小，默认`500`                                                 |
| `chunk_character`    | string | 否   | JSON 数组字符串，例如`["。","\\n"]`                                 |
| `similarity`         | float  | 否   | 语义切分阈值，默认`0.6`                                             |
| `model`              | string | 否   | LLM 模型名                                                            |
| `base_url`           | string | 否   | OpenAI-compatible LLM 地址                                            |
| `knowledge_space_id` | string | 否   | 知识空间 ID                                                           |

自动解析策略：DOC/DOCX 优先 Docling，复杂 DOCX 自动转 MinerU；文本型 PDF 使用 Docling，扫描或复杂 PDF 使用 MinerU；XLS/XLSX/CSV 固定使用 Pandas；HTML/HTM 固定使用 BeautifulSoup。不兼容的显式引擎会在加载模型前返回错误，自动模式下 Docling/MinerU 失败会尝试另一引擎。

### 响应参数

| 字段                   | 类型   | 说明                              |
| ---------------------- | ------ | --------------------------------- |
| `code`               | int    | `0` 表示成功，非 0 表示业务失败 |
| `info`               | string | 提示信息                          |
| `data.name`          | string | 文件名，不含扩展名                |
| `data.understanding` | string | 知识自然语言理解摘要              |
| `data.origin_url`    | string | 解析后 Markdown 文件地址          |
| `data.vector_url`    | string | 向量化结果文件地址                |
| `data.extract_url`   | string | 知识抽取结果文件地址              |
| `data.graphs`        | object | 图谱结果，包含节点和关系          |
| `data.stats`         | object | 处理统计信息                      |

接口按统一的 PlantUML 本体方言解释类和属性：推荐使用引号类名作为展示名、`as Alias` 作为稳定的元模型类型标识，
构造型用于分类或父类型，例如 `class "术语" as Terminology <<KnowledgeUnit>>`。
为兼容现有本体，没有 alias 时第一个构造型作为类型标识，因此
`class 术语 <<Terminology, KnowledgeUnit>>` 也返回 `label: "Terminology"`。
属性末尾括号内的英文名是稳定属性标识，例如
`术语标准名称 (TermName): String` 返回属性 `TermName`。没有扩展标识时回退为原 PlantUML 名称。

完整的本体格式、解析优先级、输入输出示例和支持边界参见
[`algorithm/knowledge_extract/README.md`](algorithm/knowledge_extract/README.md)。

### 请求示例

```bash
curl -X POST http://127.0.0.1:8080/api/knowledge/precipitation \
  -F 'file=@./demo.html' \
  -F 'ontology=@./ontology.puml' \
  -F 'chunk_type=0' \
  -F 'knowledge_space_id=ks-demo'
```

### 响应示例

```json
{
  "code": 0,
  "info": "success",
  "data": {
    "name": "demo",
    "understanding": "本知识描述了业务域中的核心实体与关系...",
    "origin_url": "/file/xxx/demo.md",
    "vector_url": "/file/xxx/demo_vector.md",
    "extract_url": "/file/xxx/demo_extract.md",
    "graphs": {
      "graphs": [
        {
          "graph": {
            "index": "0",
            "nodes": [],
            "relationships": []
          }
        }
      ]
    },
    "stats": {}
  }
}
```

## 2. 批量文本向量化接口

将多段文本转换为向量表示。

| 项目         | 说明                                                                   |
| ------------ | ---------------------------------------------------------------------- |
| URL          | `POST /api/component/nl2cypher/text-to-vectors`                      |
| 完整地址     | `POST http://127.0.0.1:8080/api/component/nl2cypher/text-to-vectors` |
| Content-Type | `application/json`                                                   |
| 认证方式     | 无                                                                     |

### 请求示例

```json
{
  "texts": ["知识地图", "接口烟测"]
}
```

### 响应示例

```json
{
  "code": 0,
  "info": "批量文本转向量完成，共 2 个向量",
  "message": "批量文本转向量完成，共 2 个向量",
  "data": {
    "count": 2,
    "texts": ["知识地图", "接口烟测"],
    "vectors": [[0.1234], [-0.2345]],
    "items": [
      {"index": 0, "text": "知识地图", "vector": [0.1234]},
      {"index": 1, "text": "接口烟测", "vector": [-0.2345]}
    ]
  },
  "error": null
}
```

批量接口保留输入顺序和空字符串，不再静默过滤输入项。

## 3. 置信度更新接口

对输入 graph 中的关系进行置信度评估，并把置信度写入 `relationships[i].properties.confidence` 后返回。

| 项目         | 说明                                                                        |
| ------------ | --------------------------------------------------------------------------- |
| URL          | `POST /api/component/kg-update/calculate-confidence`                      |
| 完整地址     | `POST http://127.0.0.1:8080/api/component/kg-update/calculate-confidence` |
| Content-Type | `application/json`                                                        |
| 认证方式     | 无                                                                          |

### 请求示例

```json
{
  "graph": {
    "nodes": [
      {
        "uid": "businessobject::招采公开项目",
        "label": "BusinessObject",
        "properties": {
          "name": "招采公开项目"
        }
      },
      {
        "uid": "stakeholder::采购管理部门",
        "label": "Stakeholder",
        "properties": {
          "name": "采购管理部门"
        }
      }
    ],
    "relationships": [
      {
        "from_uid": "businessobject::招采公开项目",
        "to_uid": "stakeholder::采购管理部门",
        "type": "HAS_STAKEHOLDER"
      }
    ]
  }
}
```

### 响应示例

```json
{
  "code": 0,
  "info": "置信度评估完成",
  "data": {
    "evaluation_id": "EVAL-20260706-001",
    "total_count": 1,
    "graph": {
      "nodes": [],
      "relationships": [
        {
          "from_uid": "businessobject::招采公开项目",
          "to_uid": "stakeholder::采购管理部门",
          "type": "HAS_STAKEHOLDER",
          "properties": {
            "confidence": 0.79
          }
        }
      ]
    },
    "details": {}
  }
}
```

## 5. 文件存储接口

用于算法服务内部和调用方调试时上传文件。该接口在 8080 上提供本地 mock 存储。

| 项目         | 说明                                       |
| ------------ | ------------------------------------------ |
| URL          | `POST /third/files/upload`                      |
| 完整地址     | `POST http://127.0.0.1:8080/third/files/upload` |
| Content-Type | `multipart/form-data`                    |
| 认证方式     | 无                                         |

### 请求参数

| 字段                 | 类型   | 必填 | 说明        |
| -------------------- | ------ | ---- | ----------- |
| `file`             | file   | 是   | 上传文件    |
| `knowledgeSpaceId` | string | 否   | 知识空间 ID |

### 响应示例

```json
{
  "code": 0,
  "info": "success",
  "msg": "success",
  "data": {
    "id": "f2c6b9dc-86b6-43af-8bd0-94256c244bd1",
    "file_name": "demo.pdf",
    "file_path": "/abs/path/to/file",
    "file_url": "/file/f2c6b9dc-86b6-43af-8bd0-94256c244bd1/demo.pdf",
    "knowledgeSpaceId": "ks-demo"
  }
}
```

| 项目         | 说明                                       |
| ------------ | ------------------------------------------ |
| URL          | `POST /vector/save`                      |
| 完整地址     | `POST http://127.0.0.1:8080/vector/save` |

### 请求示例

```json
{
  "items": [
    {
      "vector": [0.1, 0.2, 0.3],
```

```json
{
  "code": 0,
  "msg": "success",
  "info": "success",

    "id": "4a6f7c8e-f856-40f8-890b-8aa34e9ee031",
    "saved_path": "/abs/path/to/vector.json",
    "item_count": 1
  }
}
```
