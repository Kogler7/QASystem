# 中国中车股份有限公司办公室

中国中车核心商密3年

# 关于印发《轨道交通装备行业高质量数据集链主任务工作方案》的通知

齐车集团、长客股份公司、大连公司、唐山公司、大同公司、永济电机公司、四方股份公司、浦镇公司、戚墅堰公司、长江集团、株机公司、株洲电机公司、大连所、四方所、戚墅堰所、株洲所行政、信息公司、中车研究院、重庆公司，科技质量与信息化部、铁路业务事业部、城市交通事业部：

根据国家数据局行业高质量数据集建设链主任务要求，股份公司编制了《轨道交通装备行业高质量数据集链主任务工作方案》（见附件），请各承担单位按照任务分工进行分解落实，健全项目管理机制，加强资源投入，确保按计划完成项目实施，打造人工智能高质量数据集建设标杆示范。
