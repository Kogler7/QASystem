## 关于印发中国中车数智转型专项方案的通知

中国中车集团有限公司各一级子公司，中国中车股份有限公司各一级子公司，总部各部门：

按照中国中车数智转型“1116”总体目标要求，结合公司战略、职能规划和业务规划，集团公司完成了各业务数智转型专项方案编制、评审、意见征集及修订完善，现予以印发，请总部各部门、各子公司抓好贯彻落实，并按照以下要求做好相关工作。

一、推动数智转型任务建设。总部各部门要按照中车数智转型方法论及“六统一”（统一规划、统一标准、统一投资、统一建设、统一运营、统一管控）原则开展本业务数智转型任务建设，组织子公司完善本业务域两级一体化流程架构，推动本业务域

L1-L3 统一、L4-L6 统筹；开展各业务域数据治理工作，识别梳理业务对象、制定数据标准、搭建数据模型，形成中车整体数据资源目录，业务数据按照两级数据管理平台方式实现数据贯通。

二、完善数智转型发展规划（2025-2030）。结合各业务专项方案、数智转型咨询成果，数智办要牵头完善数智转型发展规划（2025-2030），发布中车数智转型蓝图、全景图、路线图、方法论及一体化企业架构，研究制定中车数智转型管理制度及系列标准，组织开展数智转型评价，结合中车“双赛道双集群”产业特点组织制定中车数智转型场景图谱。

三、完善子公司数智转型发展规划（2025-2030）及实施方案。各子公司要做好专项方案承接工作，按照专项方案要求，结合企业实际，制定各业务数智转型方案，并完善到子公司数智转型发展规划（2025-2030）及实施方案。子公司数智转型顶层规划及项目建设应遵循中车数智转型方法论及“六统一”原则，数智转型项目需统一投资预算。

四、开展数智转型两级培训。总部各部门要于10月底前组织完成本业务域数智转型专项方案培训，培训内容包含业务规划、主要建设内容、数智转型方法论等，数智办各部门协助做好方法论培训。按照集团人力部年度培训计划，11月底前数智办要组织开展总部、子公司两层数智转型顶层规划及方法论培训。

五、其他要求。子公司数智转型发展规划（2025-2030）及实施方案上报时间调整为2025年10月20日前报送至数智办邮箱，
